## Dataset1_Resistance_Haplotypes_Microsat_Coord.xlsx

First sheet: Haplotypes_mtDNA_Resistance
- Sample Name = number depicting sample ID
- Site Number = sampling site ID
- Site = sampling site ID detailed
- Capture Date = date of sampling
- Host species = *H. sapiens* (human) or *M. myotis* (bat)
- Haplotype = Haplotype ID after concatenating 16S and COI mtDNA sequences
- Resistance = Different haplotypes for the 3 amino acids
- V419L = Resistance haplotype for the amino acid 419
- L925I = Resitsance haplotype for the amino acid 925
- I936F = Resitsance haplotype for the amino acid 936
- Microsatellite = y if sample present in the microsatellite dataset

Second sheet: Coordinates
Coordinates for each sampling sites
- Approx. = the coordinates were approximated because the exact sampling location was not available
